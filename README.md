# «Вкус и Дело» — сайт-витрина

Копчёности и крафтовые колбасы, Луховицы. Каталог, умный поиск, корзина, приём заявок в Telegram и на почту, простая админка.

**Стек.** Astro собирает сайт в обычные HTML-страницы: они быстро открываются на телефоне, хорошо индексируются и стоят копейки в поддержке. Поиск работает прямо в браузере на MiniSearch (каталог небольшой), а заявки и админку обслуживает один файл на Node.js без внешних сервисов. Поэтому сайт можно разместить на любом российском VPS за 200–400 ₽ в месяц.

```
src/data/products.json    ← товары (цены, статусы, фото, теги для поиска)
src/data/site.json        ← контакты, реквизиты, ближайшая партия, хиты, Метрика
src/data/categories.json  ← категории
src/data/synonyms.json    ← синонимы для поиска
public/images/            ← фото товаров (products/) и главного экрана (hero/)
src/lib/search-core.js    ← поисковый движок (стемминг, синонимы, опечатки)
src/scripts/              ← JS в браузере: корзина, поиск, фильтры
server/index.mjs          ← сервер: сайт + заявки + админка /admin
docs/                     ← концепция, тесты поиска, плейсхолдеры, чек-лист запуска
```

---

## 1. Запуск

Нужен Node.js 20.12 или новее.

```bash
npm install
cp .env.example .env      # заполните пароль админки и Telegram-бота
npm run build             # собрать сайт в dist/
npm start                 # http://localhost:3000, админка — http://localhost:3000/admin
```

Для разработки с мгновенным обновлением: `npm run dev` (http://localhost:4321). В этом режиме форма заявки не работает, потому что сервера нет: заявки проверяйте через `npm start`.

Проверка поиска: `npm run test:search` (24 сценария, подробнее в [docs/SEARCH-TESTS.md](docs/SEARCH-TESTS.md)).

## 2. Как менять товары, цены, статусы и фото

### Через админку (для владельца)

1. Откройте `https://ваш-сайт.ru/admin` и введите логин `admin` и пароль из `.env`.
2. **Товары**: статус («В наличии / Будет к дате / Под заказ») меняется прямо в списке. Кнопка «Изменить» открывает всё остальное: цену, описание, состав, вес, фото (можно грузить прямо с телефона, фото само сожмётся в WebP), «новинку», «хит», «С этим берут».
3. **Партия и витрина**: дата ближайшей партии, что в неё входит, хиты на главной, «Популярное» в поиске.
4. **Контакты и реквизиты**: телефон, ИНН, адрес самовывоза, номер Метрики, фото для главного экрана.
5. Нажмите **«Опубликовать на сайте»**. Сайт пересоберётся за 10–30 секунд без остановки.

Там же видны **Заявки**, сообщения из формы «Контакты» и вкладка **Поиск**: что люди искали и **не нашли**. Это прямая подсказка, чего не хватает в каталоге или какие слова добавить в синонимы.

### Вручную (для разработчика)

Отредактируйте `src/data/products.json` и выполните `npm run build`. Поля товара:

| Поле | Что это |
|---|---|
| `id` | адрес страницы: `/catalog/<id>` (латиница, дефисы) |
| `price` | число или `null` («Цена по запросу») |
| `priceUnit` | `kg` — за килограмм, `pcs` — за штуку/упаковку |
| `sellBy` | `piece` — штуками (батон, упаковка), `weight` — на развес с шагом 0,5 кг |
| `weight` | `{ "min": 500, "max": 600 }` в граммах: по нему считается примерная сумма |
| `status` | `in_stock` · `soon` (+ `statusDate`) · `preorder` |
| `image`, `gallery` | `/images/products/файл.webp`. Пусто — фирменная заглушка с силуэтом `icon` |
| `tags` | слова, по которым товар должен находиться |
| `noPork` | `true` / `false` / `null`, управляет чипом «Без свинины» |
| `extra.shelfLife`, `extra.storage` | срок годности и хранение. Пока пусто, на сайте не выводятся |

Фото без правки кода: положите файл в `public/images/products/` и укажите путь в поле `image`. Лучше всего WebP 1200–1400 px.

## 3. Подключение Telegram-бота

1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя → получите **токен** вида `1234567890:AA...`.
2. Напишите своему боту любое сообщение (иначе он не сможет вам писать).
3. Узнайте свой **chat_id**: откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":123456789`. Для группы добавьте бота в группу, напишите в ней сообщение, и id будет отрицательным.
4. Впишите в `.env`:
   ```
   TELEGRAM_BOT_TOKEN=1234567890:AA...
   TELEGRAM_CHAT_ID=123456789
   ```
   Можно несколько получателей через запятую.
5. Перезапустите сервер и оформите тестовую заявку.

**E-mail-дубль** (необязательно): заполните `SMTP_*` и `MAIL_TO` в `.env`. Для Яндекс.Почты: `smtp.yandex.ru`, порт 465, пароль приложения из настроек безопасности Яндекс ID.

Все заявки дополнительно сохраняются в `storage/orders.json` и видны в админке, даже если Telegram недоступен. Если не настроен ни один канал, сервер пишет об этом предупреждение в лог.

**Защита от спама:** скрытое поле-ловушка (honeypot), отсев форм, отправленных быстрее чем за 2,5 секунды, лимит 5 корректных заявок с одного IP за 10 минут (`ORDER_LIMIT`). Цены и суммы сервер пересчитывает по каталогу и не берёт из браузера.

Кнопка «Заказать в Telegram» в корзине открывает чат с @SanyaLem с уже набранным текстом заказа (ссылка `t.me/SanyaLem?text=...`).

## 4. Как работает поиск и как добавлять синонимы

- Стеммер Портера для русского языка: «колбаски», «колбасу» и «колбаса» приводятся к одной основе. Буквы ё и е считаются одинаковыми.
- Опечатки прощаются: 1 ошибка в словах из 5–7 букв, 2 в длинных («серваелат» → сервелат). Слова, разорванные пробелом, тоже находятся («серв элат»).
- Вес совпадения: название > теги > категория > состав > описание. Точное совпадение названия и начало слова получают бонус.
- Сначала ищутся товары со **всеми** словами запроса, если таких нет, то с **любым** из них.
- Индекс строится в браузере один раз (MiniSearch + словари ~8 КБ gzip, грузятся отдельно при первом поиске; весь остальной JS сайта ~16 КБ gzip) и дальше работает мгновенно и без сети.

**Синонимы** — вкладка «Синонимы» в админке или файл `src/data/synonyms.json`:

```jsonc
{
  "groups": [                       // взаимные: любое слово находит остальные
    ["курица", "курочка", "кура", "куры", "птица"]
  ],
  "oneWay": {                       // односторонние: «колбаса» найдёт сервелат, но не наоборот
    "колбаса": ["сервелат", "ветчина", "краковская"]
  }
}
```

Окончания писать не нужно. После изменения выполните `npm run test:search`: тесты покажут, если что-то сломалось.

Горячие клавиши: `/` или `Ctrl+K` (`Cmd+K`) открывают поиск, `↑ ↓` выбирают результат, `Enter` открывает товар, `Esc` закрывает поиск.

## 5. Аналитика (Яндекс.Метрика)

Укажите номер счётчика в админке («Контакты и реквизиты») или в `site.json → metrikaId`. Сайт отправляет цели (их нужно создать в Метрике как «JavaScript-событие» с теми же идентификаторами):

| Цель | Когда |
|---|---|
| `search` | поисковый запрос (параметры: query, results) |
| `search_no_results` | запрос без результатов |
| `search_click` | клик по результату поиска |
| `add_to_cart` | добавление в корзину |
| `order_submit` | отправка заявки |
| `phone_click`, `telegram_click` | клик по телефону / Telegram |
| `telegram_order`, `batch_signup`, `contact_submit` | заказ в Telegram, запись на партию, форма контактов |

## 6. Размещение (хостинг в РФ)

Подойдёт любой VPS с Ubuntu (Timeweb Cloud, Selectel, REG.RU, Beget VPS) от 1 ГБ RAM:

```bash
# на сервере
git clone <репозиторий> /opt/vkusidelo && cd /opt/vkusidelo   # или загрузите архив
npm ci && npm run build
cp .env.example .env && nano .env      # TRUST_PROXY=1, FORCE_HTTPS=1
sudo cp deploy/vkusidelo.service /etc/systemd/system/ && sudo systemctl enable --now vkusidelo
sudo apt install caddy && sudo cp deploy/Caddyfile /etc/caddy/Caddyfile   # впишите домен
sudo systemctl reload caddy            # Caddy сам выпустит и продлит SSL-сертификат
```

Конфиги лежат в [deploy/](deploy/). Папку `storage/` (заявки, журнал поиска) включите в резервное копирование.

**GitHub Pages (бесплатно, без сервера):** репозиторий должен называться `ЛОГИН.github.io` (или подключите свой домен), в Settings → Pages → Source выберите «GitHub Actions». Файл `.github/workflows/deploy.yml` сам собирает сайт при каждом изменении. В этом режиме заявки и форма контактов открывают Telegram с готовым текстом; админки и журнала поиска нет — товары правятся в `src/data/products.json` прямо на github.com (карандаш «Edit» → «Commit changes»), фото загружаются в `public/images/products/` кнопкой «Add file → Upload files».

**Без сервера:** папку `dist/` можно выложить на любой статический хостинг. Каталог, поиск и корзина будут работать, а при отправке формы покупатель увидит предложение отправить готовый заказ в Telegram. Но заявки с сайта, админка и журнал поиска без Node-сервера работать не будут.
