# Чек-лист запуска

## Домен и хостинг
- [ ] Купить домен (.ru / .рф) у российского регистратора (REG.RU, RU-CENTER, Timeweb).
- [ ] Арендовать VPS в РФ (Timeweb Cloud, Selectel, REG.RU), Ubuntu 22/24, от 1 ГБ RAM.
- [ ] A-запись домена (и `www`) → IP сервера.
- [ ] Установить Node.js 20+ и выполнить шаги из README → «Размещение».
- [ ] Вписать домен в `deploy/Caddyfile` и в админку («Адрес сайта»), затем «Опубликовать».

## SSL и безопасность
- [ ] Caddy выпустил сертификат: сайт открывается по `https://`, а `http://` перенаправляет на https.
- [ ] В `.env`: `TRUST_PROXY=1`, `FORCE_HTTPS=1`, длинный `ADMIN_PASSWORD`.
- [ ] Права на `.env`: `chmod 600 .env`.
- [ ] Резервная копия `storage/` и `src/data/` (cron + rsync или снапшоты VPS).

## Заявки
- [ ] Создан бот в @BotFather, токен и chat_id в `.env`.
- [ ] Тестовая заявка с телефона пришла в Telegram (и на почту, если настроена).
- [ ] Заявка видна в админке → «Заявки».
- [ ] Кнопка «Заказать в Telegram» открывает чат @SanyaLem с готовым текстом.

## Контент
- [ ] Заполнены все пункты из [PLACEHOLDERS.md](PLACEHOLDERS.md) (реквизиты, цены, статусы, история мастера).
- [ ] Загружены фото товаров (хотя бы хитов) и фото главного экрана.
- [ ] Проставлены реальные статусы и дата ближайшей партии.

## Яндекс.Метрика
- [ ] Создать счётчик на metrika.yandex.ru, номер указать в админке.
- [ ] Создать цели «JavaScript-событие»: `search`, `search_no_results`, `search_click`, `add_to_cart`, `order_submit`, `phone_click`, `telegram_click`, `telegram_order`, `batch_signup`, `contact_submit`.
- [ ] Проверить в режиме отладки (`?_ym_debug=1`), что цели срабатывают.

## Яндекс.Вебмастер и поиск
- [ ] Добавить сайт в webmaster.yandex.ru, подтвердить права.
- [ ] Отправить `https://домен/sitemap.xml`.
- [ ] Указать регион сайта: **Луховицы**.
- [ ] Проверить микроразметку (Инструменты → Валидатор микроразметки): Store, Product, BreadcrumbList, FAQPage.
- [ ] Проверить превью для Telegram: отправить ссылку себе в «Избранное» (картинка `og.jpg`). Если превью старое — @WebpageBot.

## Яндекс.Бизнес и Яндекс.Карты
- [ ] Зарегистрировать организацию на business.yandex.ru: «Вкус и Дело», Луховицы, категории «Мясная продукция», «Колбасы», «Производство мясных изделий».
- [ ] Если есть точка самовывоза — указать адрес (тогда он появится на Картах); если нет — выбрать «Работаю без офиса, выезжаю к клиентам / доставка» и указать зону Луховицы.
- [ ] Телефон, сайт, Telegram, фото продукции, часы работы.
- [ ] Добавить адрес и координаты самовывоза в админку, чтобы на странице «Контакты» появился маркер.
