# Что нужно заполнить владельцу

Почти всё заполняется в админке (`/admin`), без правки кода.

## Обязательно до запуска

| Что | Где | Сейчас |
|---|---|---|
| Адрес сайта (домен) | Админка → Контакты и реквизиты → «Адрес сайта» (`site.json → url`) | `https://example.ru` |
| Форма: ИП или самозанятый | там же → Реквизиты | `[УКАЗАТЬ]` |
| ФИО | там же | `[УКАЗАТЬ]` |
| ИНН | там же | `[УКАЗАТЬ]` |
| ОГРНИП (для ИП; самозанятому — оставить пустым) | там же | `[УКАЗАТЬ]` |
| Пароль админки | `.env → ADMIN_PASSWORD` | — |
| Telegram-бот для заявок | `.env → TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | — |
| Номер счётчика Яндекс.Метрики | Админка → Контакты и реквизиты | пусто (Метрика выключена) |
| Дата редакции политики и соглашения | `src/pages/privacy.astro`, `src/pages/terms.astro` | `[УКАЗАТЬ: дата]` |
| Срок хранения персональных данных | `src/pages/privacy.astro` | `[УКАЗАТЬ: срок]` |

## Каталог

| Что | Сейчас |
|---|---|
| Цена: Сырокопчёный карбонат | «Цена по запросу» |
| Цена: Карбонат горячего копчения (свиная шея) | «Цена по запросу» |
| Цена и единица продажи: Мясо перепела (тушка? кг?) | «Цена по запросу», продаётся тушками |
| **Статусы всех товаров и дата партии — демонстрационные** (31 октября) | проверьте и проставьте реальные |
| Фото товаров | фирменные заглушки |
| Фото для главного экрана | иллюстрация |
| Состав у позиций, где он не указан (Краковская, Финский, Чесночный, Ветчина, Грудинка, Сырокопчёный карбонат) | «Подробный состав подскажу по запросу» |
| Флаг «Без свинины» (`noPork`). Сейчас `true` у курицы, крылышек, карпаччо, печени и сердечек, мяса перепела. Убедитесь, что в рецептуре нет свинины/шпика | чип «Без свинины» в каталоге |
| Тексты описаний: проверьте, что всё соответствует действительности | черновики по данным из канала |

## Тексты

| Что | Где |
|---|---|
| История мастера, имя: метки `[ДОПИСАТЬ]` | `src/pages/about.astro` |
| Фото мастера | `src/pages/about.astro` (сейчас заглушка) |
| Адрес самовывоза и координаты (по желанию: пусто — адрес не показывается, на карте нет маркера) | Админка → Контакты |
| E-mail для политики конфиденциальности (по желанию) | Админка → Контакты |
| Отзывы — только реальные, с согласия покупателей | `site.json → reviews.items`, затем включить галочку в админке |
