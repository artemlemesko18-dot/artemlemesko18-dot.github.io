## Ручная проверка в браузере

1. Нажмите `/` на любой странице: откроется поиск, курсор уже в поле.
2. При пустом поле видны «Недавние запросы» (с кнопкой «Очистить») и «Популярное».
3. Введите «серв»: через ~160 мс появятся сервелаты, совпадение подсвечено.
4. `↓` `↓` `Enter` откроют второй результат, `Esc` закроет поиск.
5. «Показать все результаты (N)» ведёт на `/search?q=серв`. Этой ссылкой можно поделиться, фильтры тоже сохраняются в адресе.
6. Введите «пицца»: появится пустое состояние, а в админке на вкладке «Поиск» запрос окажется в списке «Искали, но не нашли».
