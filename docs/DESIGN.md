# Карта сайта и дизайн-концепция

## Карта сайта

```
/                          Главная
├─ /catalog                Каталог (фильтры и сортировка в адресе: ?category=…&status=…&min=…&max=…&sort=…&new=1&nopork=1)
│  └─ /catalog/<id>        Страница товара (18 шт.)
├─ /search?q=…             Результаты поиска (шарингуемая ссылка, noindex)
├─ /about                  О нас
├─ /how-to-order           Как заказать + FAQ
├─ /contacts               Контакты, карта, форма обратной связи
├─ /privacy                Политика конфиденциальности (152-ФЗ)
├─ /terms                  Пользовательское соглашение
├─ /404                    Фирменная страница «ушла в дым»
├─ /admin                  Админка (пароль)
└─ /sitemap.xml, /robots.txt, /catalog-data.json
```

Главная сверху вниз: шапка → hero с поиском → «Сейчас в наличии и ближайшая партия» → хиты и новинки → категории → «Почему нас выбирают» → «Как заказать» → отзывы (скрыты, пока нет настоящих) → «Мы в Telegram и MAX» → подвал.

## Идея

**Тёплый дымный крафт.** Тёмный графитово-коричневый фон, как коптильня вечером, на нём кремовый текст и медно-янтарные акценты, как тлеющие угли. Контрастные кремовые секции работают как «разделочная доска» и дают ритм. Интерфейс чистый и в духе Linear/Stripe: крупная типографика, много воздуха, тонкие полупрозрачные границы, мягкое стекло.

## Палитра

| Токен | Тёмная (основная) | Светлая | Назначение |
|---|---|---|---|
| `--bg` | `#14100E` | `#F5EDE0` | фон |
| `--bg-2` | `#1B1512` | `#EFE4D3` | альтернативный фон |
| `--surface` | `#221B17` | `#FBF7F0` | карточки |
| `--text` | `#F5EDE0` | `#1E1815` | основной текст |
| `--accent` | `#E8A35A` | `#9A4521` | ссылки и акцентный текст (контраст AA на фоне) |
| `--olive` | `#B5C487` | `#4C5A26` | «В наличии», второй акцент (зелень, чеснок) |
| `--grad` | `#E7A050 → #D58340 → #C4643A` || кнопки, тёмный текст `#1A0F08` поверх |

Градиент кнопки чуть светлее, чем `#D98E3B → #B5532A` из брифа: тогда тёмный текст держит контраст AA (≥ 4,5:1) по всей кнопке, а белый на янтаре этого не даёт. Секции `.section--contrast` автоматически инвертируют тему. Hero тёмный в обеих темах.

Тема: по умолчанию берётся из `prefers-color-scheme`, а переключатель в шапке запоминает выбор.

## Типографика

- **Заголовки:** Playfair Display (вариативный, кириллица), курсив для акцентных слов («*с неповторимым характером*»).
- **Текст и интерфейс:** Manrope (вариативный, кириллица).
- Шрифты свои (без Google Fonts) с `font-display: swap`, браузер грузит только нужные наборы символов.
- Fluid-размеры через `clamp()`: hero 40 → 88 px, H1 34 → 60 px, H2 28 → 48 px. Ширина абзацев 60–70 символов.

## Компоненты

| Компонент | Особенности |
|---|---|
| Шапка | липкая, стекло с blur после прокрутки, поле-кнопка поиска с подсказкой `/`, корзина со «скачущим» счётчиком |
| Поиск | комбобокс WAI-ARIA, выпадающая панель (hero) или полноэкранная палитра (мобильный / `Ctrl+K`), подсветка `<mark>`, скелетоны, пустое состояние с чипами и Telegram |
| Карточка товара | фото 4:3.4 с zoom при наведении, бейдж статуса, «Новинка»/«Хит», цена + вес, кнопка «В корзину» превращается в счётчик |
| Плейсхолдер фото | градиент в цвет категории + линейный силуэт продукта (11 видов) + подпись «Фото скоро» |
| Бейджи статусов | олива — в наличии, янтарь — будет к дате, медь — под заказ |
| Блок партии | крупная дата, два списка (в наличии / к партии), кнопка «Записаться на партию» |
| Корзина | выезжающая панель, два шага (состав → контакты), примерная сумма, «итог после взвешивания» |
| Модалка «Спасибо», тосты, cookie-баннер, FAQ-аккордеон | |

Скругления 16–24 px. Анимации 150–350 мс (`cubic-bezier(.22,.61,.36,1)`): появление блоков при скролле, подъём карточек, пружинка счётчика. «Дым» в hero — три мягких градиентных пятна, двигается только `transform`/`opacity`. Он ставится на паузу вне экрана и отключается при `prefers-reduced-motion`, на слабых устройствах (≤ 2 ядер / ≤ 2 ГБ памяти) и в режиме экономии трафика.

Иконки — Lucide (линейные, толщина 1,75), эмодзи в интерфейсе нет.

## Макеты

**Главная (мобильный, 360–430 px):** hero на весь экран, поле поиска во всю ширину, кнопки «Каталог» и «Заказать в Telegram» → карточка партии → карусель хитов, листается пальцем → плитки категорий 2 в ряд → преимущества и шаги столбцом.

**Главная (десктоп):** hero с иллюстрацией справа → партия в две колонки (дата слева, списки справа) → 4 хита в ряд → плитки категорий 3+2 → 4 преимущества → 4 шага.

**Каталог:** чипы-подборки (Горячее копчение, Для жарки, Колбасы, Паштеты, Новинки, Без свинины) → счётчик, «Фильтры», сортировка → раскрывающаяся панель фильтров → сетка 2 / 3 / 4 колонки.
